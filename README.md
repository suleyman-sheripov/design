# Портфолио Сулеймана Шерипова

Статический сайт без сборщика: HTML, CSS и модули ES. Никаких зависимостей,
никакого npm install. Файлы отдаются как есть, поэтому GitHub Pages хватает.

Направление и правила оформления лежат в [DESIGN.md](DESIGN.md).

## Что где

```
index.html          первый экран, работы, опыт, инструменты, контакты
admin/              админка: правит содержимое через GitHub API
css/                tokens → base → cursor → hero → work → tools → contact
js/
  physics.js        пружины, верле и общий такт rAF. Отсюда всё движение
  intro.js          сборка замка в шапке
  cursor.js         приводочная метка вместо системного курсора
  symbiote.js       капля, которая тянется к руке от главной кнопки
  lettering.js      буквы адреса, тянущиеся к руке
  bough.js          ветка-маятник на первом экране
  work.js           лента кейсов и разбор в <dialog>
  tools.js          короб с фишками инструментов
  main.js           сборка страницы и чтение data/*.json
data/
  profile.json      контакты, опыт, инструменты
  projects.json     кейсы и снимки
assets/
  work/             снимки кейсов в webp
  tools/            значки программ
  branch.webp       ветка с первого экрана
```

Содержимое живёт в `data/*.json`, а не в разметке. Так админка правит
тексты, не трогая вёрстку.

## Локальный запуск

Нужен любой статический сервер: модули ES и `fetch` по `file://` не работают.

```bash
node .claude/dev-server.mjs
```

Дальше `http://localhost:4321`, админка на `http://localhost:4321/admin/`.

## Админка

`/admin/` правит `data/profile.json` и `data/projects.json` напрямую
в репозитории. Своего сервера у сайта нет, поэтому нужен личный токен.

1. GitHub → Settings → Developer settings → Personal access tokens →
   Fine-grained tokens → Generate new token.
2. Repository access: только этот репозиторий.
3. Permissions → Repository permissions → **Contents: Read and write**.
4. Скопировать токен и вставить в поле на `/admin/`.

Токен сохраняется в `localStorage` того браузера, где его ввели, и уходит
только на `api.github.com`. На чужом компьютере после работы нужно нажать
«Выйти»: кнопка стирает токен.

Что умеет:

- контакты, опыт и список инструментов;
- кейсы: название, тип, роль, год, описание, порядок;
- загрузку снимков. Картинка ужимается в браузере до 1600 px по длинной
  стороне и кладётся в `assets/work/` в webp, чтобы в репозиторий
  не попадали мегабайтные PNG.

После сохранения GitHub Pages пересобирает страницу, обычно за минуту.
