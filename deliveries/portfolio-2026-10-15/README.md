# Сайт портфолио — все материалы

[Скачать полный ZIP](https://github.com/suleyman-sheripov/design/releases/download/portfolio-materials-2026-10-15/SHERIPOV-portfolio-all-2026-10-15.zip)

[Страница архива в Releases](https://github.com/suleyman-sheripov/design/releases/tag/portfolio-materials-2026-10-15)

Внутри — папка «Сайт портфолио»: готовые баннеры Behance и LinkedIn,
логотипы, исходники, все предыдущие версии, снимок кода сайта,
первый логобук и новый визуальный кейс с пятью готовыми ИИ-мокапами.
Всего 991 файл. После распаковки папку можно загрузить в Google Drive.

Для Git архив разделён на три части меньше 100 МБ. GitHub Actions
проверяет их, восстанавливает единый ZIP и прикрепляет его к Release.
Главная ветка и опубликованный сайт при этом не меняются.

Если нужен архив из локальной копии этой ветки, запустите Python 3:

```sh
python deliveries/portfolio-2026-10-15/restore_archive.py
```

Контрольные суммы полного архива и всех частей — в `manifest.json`.
Оригинальный файл в чате назывался «Сайт-портфолио-все-файлы-2026-10-15.zip»;
для скачивания с GitHub ему дано короткое имя латиницей. Содержимое совпадает.
