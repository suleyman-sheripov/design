# Приложение

Команды и описание проекта находятся в [корневом README](../README.md).

`public/admin/` — самостоятельный редактор без зависимостей от React.
`public/admin/model.js` — общая проверка JSON для сайта, редактора и скриптов.
`public/site-config.json` — публичные настройки репозитория и аналитики, без секретов.
`public/content/` — автоматически создаваемая копия `../content/`, не источник данных.
