# Продолжение на другом компьютере

Актуальная рабочая ветка: claude-live-editor-bridge в https://github.com/suleyman-sheripov/design .
Не начинай работу с main: там может быть прежняя опубликованная версия.

## Забрать проект и запустить

Нужны Git, Node.js и npm. В терминале нового компьютера:

```powershell
git clone --branch claude-live-editor-bridge https://github.com/suleyman-sheripov/design.git
cd design
npm ci --prefix app
npm run dev --prefix app
```

Открывай адрес, напечатанный Vite, с подпутём /design/. Обычно это http://localhost:5173/design/ .
Админка: http://localhost:5173/design/admin/ .
Для проверки выбери «Открыть локальный черновик без публикации».

Если проект уже скачан, сначала сохрани собственные изменения, затем:

```powershell
git fetch origin
git switch claude-live-editor-bridge
git pull --ff-only origin claude-live-editor-bridge
npm ci --prefix app
npm run dev --prefix app
```

При расхождении веток не применяй reset --hard или force push. Сохрани свою работу отдельно и разбери различия.

## Что хранится только на старом компьютере

Несохранённые правки в открытой админке и новые картинки в памяти браузера не являются файлами Git-репозитория. Автосохранение пока не реализовано. Перед закрытием такой сессии воспользуйся существующим экспортом: JSON и новые изображения выгружаются отдельно.

GitHub-токен не входит в проект. Для локальной проверки он не нужен. Для записи в GitHub потребуется вход владельца через существующий механизм редактора. Токен не вставлять в исходники, промпты, Git или логи.

Перенос рабочей ветки не публикует сайт. Для публикации потребуется отдельное завершение и проверка. В старом docs/DEPLOY.md описаны прежние ветки и локальные пути: перед реальным развёртыванием сверяй их с актуальным состоянием, а не выполняй старые команды автоматически.
