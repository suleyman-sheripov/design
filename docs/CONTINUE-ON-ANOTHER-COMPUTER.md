Актуальная версия находится в main: https://github.com/suleyman-sheripov/design .
14 октября 2026 текущий код и инструкции перенесены в main. Ветка claude-live-editor-bridge сохранена как предыдущая рабочая ветка.

## Забрать проект и запустить

Нужны Git, Node.js и npm. В терминале нового компьютера:

```powershell
git clone --branch main https://github.com/suleyman-sheripov/design.git
cd design
npm ci --prefix app
npm run dev --prefix app
```

Открывай адрес, напечатанный Vite, с подпутём /design/. Обычно это http://localhost:5173/design/ .
Админка: http://localhost:5173/design/admin/ .
Для проверки выбери «Открыть локальный черновик без публикации».

Если проект уже скачан, сначала сохрани собственные изменения, затем:

```powershell
git fetch origin
git switch main
git pull --ff-only origin main
npm ci --prefix app
npm run dev --prefix app
```

При расхождении веток не применяй reset --hard или force push. Сохрани свою работу отдельно и разбери различия.

## Состояние на 15 октября 2026

Рабочая ветка `feat/admin-autosave-polish` основана на свежем `main` (`89404a5`). Автосохранение документа и Blob реализовано; токен остаётся в памяти. Восстановление, конфликты вкладок, ошибки хранилища и согласование с GitHub-сохранением проверены. Сохранена общая история и действующий живой iframe. Есть точечные улучшения мобильной панели, медиатеки и фокуса; визуальная концепция сайта сохранена.

Подробные результаты, повторяемые браузерные проверки и оставшийся шаг владельца: [ADMIN-ACCEPTANCE-2026-10-15.md](ADMIN-ACCEPTANCE-2026-10-15.md).

Локальные правки старой открытой админки не находятся в Git. В новой версии дождись статуса локального сохранения; для переноса на другой компьютер экспортируй JSON и новые изображения отдельно. IndexedDB принадлежит конкретному браузеру/origin. GitHub-токен не переносится и не сохраняется.

Вход владельца описан в [ADMIN.md](ADMIN.md). Публичная форма входа не является закрытой серверной сессией: настоящая защита записи — права GitHub. Реальный owner-save в тестовую ветку и полная проверка production Pages ещё требуют доступа владельца и сети; main и настройки публикации в этой задаче не менялись.
