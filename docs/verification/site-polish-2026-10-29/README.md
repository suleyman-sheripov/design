# Проверка взаимодействий, лент и звука — 29 октября 2026

## Что изменено

- Главная показывает заставку при новой загрузке, включая вкладки со старым `intro-seen`. Автоматический показ отключён при системном reduced motion, прямом адресе кейса и в предпросмотре редактора. Под главным экраном есть ручной повтор без звука и со звуком; явный запуск доступен и при reduced motion.
- Контакты в шапке раскрываются абсолютным слоем. Мобильный отступ 72px удалён. Отрицательное наложение работ на главный экран также удалено: оно перекрывало нижние кнопки на невысоких desktop-окнах.
- «Обсудить задачу» и кнопка в блоке контактов открывают нативный модальный диалог. Есть обязательные поля, фокус на имени, Escape, восстановление фокуса, копирование и сохранение текста при закрытии. По выбору владельца форма **открывает готовое письмо в почтовом приложении**; серверной отправки нет. Письмо открывается отдельно, чтобы ошибка почтового обработчика не заменяла вкладку сайта. Сообщение не заявляет об отправке.
- Лента работ пересчитывается с равномерным шагом и плавной кривизной на стыках. Радиусы витков учитывают ширину полотна. Лента в Hero и в контактах рисуется цельной заливкой, без швов между сегментами. У ширины полотна контактов убран излом от абсолютного косинуса.
- Звук синтезируется в браузере: текстурный штрих, три сухих акцента, стереопроход и низкий финальный аккорд. Старт совпадает с первым кадром. Пропуск и пауза останавливают звук плавно. Первое открытие сайта всегда беззвучное. Если браузер запрещает звук, ручной повтор всё равно работает.

## Результат проверок

122/122 теста. Production build и check:content проходят. Lint: 0 ошибок и те же 5 прежних предупреждений React.

`browser.json`: Chromium 1440×900, 390×844 с настоящим touch/pointer режимом; fallback звука проверен также при стандартном окне 1280×720. Проверены автостарт при старом маркере/перезагрузке, отсутствие сдвигов от контактов, доступность и положение ссылок, форма без перехода к кейсу, валидация, сохранение текста и фокуса, реальное создание стереобуфера Web Audio, остановка источника, silent replay, reduced motion, запрет аудио, пауза в отдельном просмотре и iframe-предпросмотр.

Дополнительно обновлённый `check-logo-motion.py` проверяет геометрию финального кадра, слой переноса в шапку, таймер без rAF, кейс после reload и доступность админки. Почтовое приложение пользователя на устройстве здесь не запускалось: проверены подготовка URI, действие формы и сохранность исходной страницы. Отправка письма остаётся действием пользователя.

Скриншоты формы используют вымышленные тестовые данные.

## Повторить

```
npm ci --prefix app
npm test --prefix app
npm run lint --prefix app
npm run build --prefix app
npm run check:content --prefix app
npm run preview --prefix app -- --port 4180
python app/scripts/check-site-polish.py http://localhost:4180/design/ /tmp/site-polish-check
python app/scripts/check-logo-motion.py http://localhost:4180/design/ /tmp/logo-motion-check
```

Браузерные сценарии требуют Python Playwright, Pillow и Chromium; путь можно указать через CHROMIUM_PATH.
