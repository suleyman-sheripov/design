# Проверка результата — 7 сентября 2026

Проверена рабочая копия ветки `react`. Удалённый репозиторий и настройки Pages не изменялись. Сборка `npm run build --prefix app` проходит без ошибок и предупреждений Vite. `npm test --prefix app`: **11 из 11**. `npm run lint --prefix app` завершается успешно; остаются шесть предупреждений React о синхронизации состояния в эффектах, cleanup ref и экспорте констант. Они не скрыты отключением правил.

## Дизайн и адаптивность

Проверены реальные снимки Chrome на 320, 360, 390, 768, 1280 и 1440 px. Проверялись композиция первого экрана, опыт, тёмная витрина, диалог кейса, новые группы услуг и контакты. Шрифты загружены из локальных WOFF2, а не заменены системными. Для сравнения исходная сборка читала те же официальные шрифты через перехват только шрифтовых запросов.

Положение верхней границы h1 относительно окна, px:

| Окно | До | После | Переполнение страницы |
|---|---:|---:|---|
| 320 × 844 | 395.5 | 117.1 | нет |
| 360 × 640 | 273.0 | 100.8 | нет |
| 390 × 844 | 373.9 | 117.1 | нет |
| 768 × 1024 | 478.9 | 486.3 | нет |
| 1440 × 900 | 452.7 | 452.7 | нет |
| 1280 × 600 | 303.0 | 303.0 | нет |

На 1440 и 1280 px положение первого экрана осталось прежним. На 768 px разница около 7 px вызвана увеличенной зоной нажатия ссылок шапки. На телефонах первый экран стал короче: начало опыта попадает в видимую область раньше.

У сенсорной кнопки собственная заливка `rgb(74,93,72)` и текст `rgb(251,247,239)`: **6.66:1**. Клавиатурный фокус кнопки закрытия — сплошная обводка 2 px, `rgb(140,168,137)` на `#14120c`: **7.20:1**. Замер сделан после перевода фокуса клавиатурой и завершения изменения стиля, а не по одному цвету при отсутствии обводки.

## Взаимодействия

- Стрелка ленты сдвинула её с 0 до 560 px; обратная вернула к 0. Перетаскивание мышью дало 560 px и не открыло кейс случайным кликом.
- При прокрутке диалога на 800 px кнопка закрытия осталась в окне на y=72 px, высота 44 px. Escape закрывает диалог.
- После 8,2 секунды на первом экране все пять строк опыта ещё ждали скролла. После входа раздела сначала открылась одна строка, затем все пять. Исправлена страховка, которая раньше раскрывала их по общему таймеру до входа раздела.
- Доступное имя h1 содержит полную фразу «Привет, я Сулейман Шерипов, графический и ui/ux дизайнер.» без опечатки. Проверено дерево доступности; озвучивание NVDA/VoiceOver не прослушивалось.
- В обычном прогоне интро выдавались rAF callbacks, а семь последовательных замеров показывают падение, смыкание и оседание. Просмотрены отдельные реальные кадры. Это не оценка плавности видео на всех устройствах.
- При намеренно остановленном rAF занавес исчез, основное содержимое перестало быть inert, специальность получила opacity=1. Этот прогон проверяет только страховку читаемости и не подтверждает анимацию.
- Повтор со звуком запускается после разрешения AudioContext; возвращаются фокус и прокрутка. Физическое воспроизведение через колонки и громкость на устройстве владельца не проверялись.

`Mark.tsx`, `Lockup.tsx` и `introSim.ts` **не изменены в Git**. Содержимое исходников совпадает; рабочие копии отличаются только переводами строк LF/CRLF после клонирования. SHA-256 после нормализации переводов строк лежат в `verification/protected-files.json`.

## Админка и контент

В браузере проверены вход, отсутствие запомненного токена по умолчанию, загрузка тестового WebP, выбор статуса и единый коммит с JSON и изображением. GitHub API был имитирован: настоящие токены и записи не использовались. Изображение в этом сценарии — тестовая фикстура; коммерческие черновики в настоящем JSON остались скрытыми.

Модульные проверки покрывают конфликт до записи и гонку при обновлении ref, 401/403, безопасные имена и ссылки, обязательные подписи/обложку, кириллицу, бинарные файлы, импорт без размножения снимков и детерминированный прогон интро.

Одна и та же production-сборка показала изменённый JSON без пересборки. При недоступном raw.githubusercontent.com показала все пять работ из резервной копии и сообщение об использовании сохранённой версии.

## Что остаётся на стороне владельца

Первый push подготовленной версии, выбор GitHub Actions в Pages и реальная проверка записи с личным токеном. Также нужны изображения четырёх коммерческих/преподавательских кейсов и endpoint собственного GoatCounter. До добавления endpoint реальная аналитика не собирается.

Сырые числовые протоколы: `verification/browser.json`, `verification/interactions.json`. Снимки вынесены в соседний каталог результата `outputs/design-review/`, чтобы не пополнять репозиторий служебными картинками.
