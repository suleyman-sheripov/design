## Лента

ScrollRibbon.tsx использует единые края и градиент для всей поверхности. Смена глубины больше не обнуляет ширину, близость кнопок не пережимает ткань. Витки проходят внутри высоты превью, а не по подписям. Задние участки маскируются собственной карточкой; передние и соединительные участки восстанавливаются поверх маски. Это устраняет вырезы на пересечениях. Карточки сохраняют движение по вертикали без деформации прямоугольника маски. После scroll/resize отрисовка догоняет композитную анимацию в течение 240 мс и затем останавливается.
